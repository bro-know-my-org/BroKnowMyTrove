# BroKnowMyTrove 文档

本目录提供产品范围、使用手册、架构与格式及开发说明。项目简介与快速开始见[项目首页](../README.md)。

BroKnowMyTrove 是离线优先的跨平台加密文件库。默认交付一个 `bkmt` 二进制：无参数或双击打开 GUI，带参数执行 CLI。密码、格式、文件管理、事务、备份与恢复均使用共享核心。

当前具备核心文件操作、CLI/GUI、备份与凭据管理，以及部分 Linux 验证。首版磁盘格式 `BKMT-1` 已冻结，产品仍未经独立安全审计；仅用于可丢弃测试数据，重要资料须另有独立副本。

## 产品范围

保险库可以位于本地、移动介质或已完整下载的云盘目录，程序与库分别定位。仅支持单人、单写者；云盘在关闭保险库后同步，不自动合并多设备修改。同机锁无法协调另一台设备。

首发范围是 Windows 11、macOS 14+、Ubuntu 24.04 的 x86_64 和 ARM64 六种组合。配置了构建目标不代表已经完成原生运行、中文输入法、文件选择器及外置介质验收。

管理普通文件和逻辑目录：导入保留明文源，导出生成明文，删除进入加密回收站；提供手动一致性密文备份。恢复密钥须单独保存，不能代替备份。密码和恢复密钥同时遗失时没有绕过认证的恢复入口。

首版不做虚拟磁盘、预览、外部编辑、无人值守解锁、后台密码缓存、自动同步、定时备份、去重、压缩或物理分卷；不保真复制 ACL、扩展属性、硬链接关系和资源分叉，不与其他保险库格式互通。

约 5 万条目、单文件 100 GiB、整库 1 TiB 是验收目标。已有的 100 GiB 往返及 10 万目录条目基线不能代替同规模文件对象、长历史或整库容量验收。

## 快速开始

按[开发指南](development.md)从源码构建，或在有可用 Release 时选择匹配系统和架构的产物。若发布附件提供 SHA-256 校验值，应在运行前核对；校验值本身不能独立认证发布者。在产物所在目录运行：

```sh
./bkmt --version
./bkmt --help
./bkmt
```

Windows 使用 `./bkmt.exe`；源码调试产物为 `target/debug/bkmt`。GUI 需要图形会话，CLI 带参数运行时不初始化 GUI。纯 CLI 构建仍使用同一名称，无参数显示帮助。

反馈提交到本项目 GitHub Issues，附版本、系统/架构和可丢弃数据的脱敏复现。不要上传密码、恢复密钥、真实敏感文件或含明文名称/路径的未脱敏记录。
